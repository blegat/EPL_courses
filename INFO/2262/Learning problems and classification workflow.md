# Learning problems and classification workflow

- Machine learning induces a model from labeled examples to generalize to
  unseen cases; unsupervised learning instead extracts structure without labels
  (`INTRO`, pp. 2–10).
- A well-defined learning problem identifies task, performance measure, and
  experience/data (`INTRO`, pp. 11–16).
- The mathematical view separates input space, output labels, hypothesis class,
  loss, training sample, and expected generalization risk (`INTRO`, pp. 14–20).
- Challenges include representation, noisy/biased data, overfitting,
  dimensionality, computational cost, and evaluation leakage (`INTRO`,
  pp. 21–34).
- The course organizes classification methods around representation,
  optimization, probabilistic assumptions, and evaluation (`INTRO`, pp. 35–40).
